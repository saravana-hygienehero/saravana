Lab 1

UI Design Fundamentals

Building my first Android screens using XML layouts, exploring LinearLayout, ConstraintLayout, and basic UI widgets to craft a clean interface for the Hygiene Hero app.

This lab taught me how much thought goes into placing a single button. I struggled initially with ConstraintLayout chains, but once it clicked, I could see how proper UI structure saves development time later. The experience made me appreciate intentional design over trial-and-error layout tweaking.

Lab 2

Interaction & Event Handling

Implementing click listeners, input validation, and intent-based screen navigation to bring the Hygiene Hero interface to life with meaningful user interactions.

Wiring up interactions revealed how Android's Activity lifecycle actually governs everything. I learned to handle button states carefully to avoid crashes when users tap rapidly. Writing clean event-handler logic made my code far more readable and maintainable going forward.
Watch on YouTube
Lab 3

Material Design Components

Applying Google's Material Design 3 guidelines — cards, FABs, snackbars, and colour theming — to give Hygiene Hero a polished, consistent look and feel.

Material Design felt like learning a visual language. The component library removed guesswork from spacing and elevation, letting me focus on the user flow instead of pixel-pushing. I now understand why design systems exist and how they scale across an entire app.
Watch on YouTube
Lab 4

Jetpack Navigation Component

Setting up the Navigation Graph, bottom navigation bar, and safe-args to enable fluid, back-stack-aware transitions between Hygiene Hero's core screens.

The Navigation Component turned what used to be a tangle of intent flags into a simple visual graph. Safe Args eliminated an entire class of type-cast bugs I had been fighting. Seeing the nav graph as a diagram helped me reason about the app's architecture at a much higher level.
Watch on YouTube
Lab 5

Room Persistence Library

Designing an SQLite-backed Room database with DAOs, Entities, and Flow-reactive queries so Hygiene Hero can persist hygiene logs offline and sync them to the cloud.

Room abstracted away raw SQL boilerplate while keeping me in control of the schema. Combining Flow with ViewModel meant the UI automatically reflected database changes — no manual refresh logic needed. This reactive pattern fundamentally changed how I think about data and UI synchronisation.

Project 1 · Lab 4+

Hygiene Hero — Navigation & Working Features

Problem: Many Malaysians lack consistent hygiene routines, especially handwashing, leading to preventable disease spread. Hygiene Hero gamifies daily hygiene tasks with streaks, badges, and progress tracking to build lasting habits.

Integrating all labs into a single coherent app was more challenging than I anticipated — design inconsistencies surfaced immediately during user testing. I learned to iterate quickly, treating every bug as design feedback rather than just a code error. This project solidified my understanding of the MVVM pattern and the value of separating concerns in Android development.

Project 2 · Lab 5 + API + Cloud

Hygiene Hero — API, Sensors & Cloud

Problem: Offline-only hygiene trackers fail users when they switch devices or lose data. This version connects to Firebase Firestore for cloud sync, uses device sensors for gesture-triggered logging, and pulls WHO hygiene tips via a REST API for contextual nudges.

Merging local Room data with Firestore taught me the complexities of offline-first architecture and conflict resolution. Implementing CameraX for handwashing verification using ML Kit was a breakthrough moment — the sensor integration made the app feel truly intelligent. This project pushed my skills into production-readiness territory and gave me confidence to build full-stack mobile solutions.

Learning Journey

Reflection

This semester's mobile application development course transformed my relationship with software. I came in knowing how to write code; I leave knowing how to build systems — architecting data flows, designing for real users, and thinking about what happens when things go wrong offline. Working on Hygiene Hero anchored every abstract concept to a purpose I genuinely care about: improving public health outcomes in Malaysia through technology that meets people where they already are — their smartphones. The SDG 6 focus was not a checkbox but a compass; every feature decision asked "does this make it easier for someone to wash their hands today?" I am proud of how far the app has evolved from a static XML screen in Lab 1 to a cloud-synced, sensor-aware application, and I am even prouder of the engineering thinking that will carry me far beyond this course.
